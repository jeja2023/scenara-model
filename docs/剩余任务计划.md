# scenara-model 剩余任务计划

**适用规范：** `景枢平台总体开发规范.md` 1.3.0

**当前版本：** `1.0.0-dev.4`

**当前成熟度：** `seed`

## 已完成基线

- Training Job、Experiment、异步流水线、任务日志、产物索引和取消/重试状态机。
- `dataset-version-input` 引用校验：授权、版本、UTC RFC3339 时间和 manifest SHA-256；ReID 已适配 `scenara.portrait.surveillance-review.v1` 布控误报复核数据集。
- 训练/导出/评估 Adapter、模型卡、Model Package、Registry、Release Approval 和 Rollout API。
- 本地 SQLite/PostgreSQL 元数据边界、local/S3/MinIO 对象存储入口、认证和审计。

## 剩余交付

| 编号 | 状态 | 任务 | 责任边界 | 验收证据 |
| --- | --- | --- | --- | --- |
| MODEL-P1 | implemented | 将现有领域 API 接入 Core 统一 IAM/服务凭据和公共 Console 代理 | Model + Core | 权限透传、审计关联、公共路径兼容测试 |
| MODEL-P2 | implemented（待外部资格） | FastReID 适配器已固定框架提交、环境锁摘要、Dataset Version、checkpoint SHA-256 与 CMC+mAP 指标契约 | Model | 可复现实验日志、配置、checkpoint SHA-256；真实 GPU/数据资格另行保留 |
| MODEL-P3 | implemented | 完成通用 Model Package、评估和发布审批本地闭环 | Model | 100 项本地回归、ModelPackageManifest、模型卡和样例 |
| MODEL-P4 | implemented（待跨仓联调） | 消费 `deployment-feedback`，验证 Core HMAC 签名、event_id 幂等与有序状态重放 | Model + Core + Contracts | 本仓 webhook、重放拒绝、审计和状态回放测试；正式订阅联调另行保留 |
| MODEL-P5 | gate implemented（待外部证据） | FastReID 强制 Rank-1/5/10、mAP、固定 test manifest 与许可证/审批引用；固定评估集和权属原件由业务方提供 | Model + 业务方 | 本仓门禁测试；固定数据集摘要、评估报告、权属原件待补 |
| MODEL-P6 | partial（待 GPU 容器与目标环境） | FastReID Linux GPU 容器、PostgreSQL/S3 探针与带 SHA-256 的备份/恢复工具已实现；本机 PostgreSQL 18.4 + MinIO 写读及恢复演练已通过 | Model + Deploy | 本机资格报告；Docker GPU 容器、目标容量、目标对象存储、离线镜像清单报告待补 |
