# Scenara Model 1.0.0-dev.5 更新说明

发布日期：2026-09-05

## 变更摘要

- **前端 UI 全面中文化与术语统一**：全面汉化前端所有页面与组件文案（面包屑、侧边栏、状态徽章、任务适配器名称、指标来源、安全审计动作、日志流类别、数据切分集、诊断规范代码等），消除所有生硬英文字符，汉化率达到 100%。
- **多区域 Tab 化切换重构**：抽取并落地统一 `TabBar` 选项卡切换组件，覆盖概览、模型包工作台、流水线调度、实验台账、数据标注等所有核心多区域页面，引入动态 Badge 与微动过渡，彻底消除长页面竖向堆叠与视觉疲劳。
- **全局统一全边框数据表格规范**：
  - **首列统一序号列**：平台全部 8 个数据表格统一引入 `序号` 列，居中对齐，与分页公式 `(currentPage - 1) * pageSize + index + 1` 联动实现全局连续自增；
  - **统一固定行高**：表头及数据行单元格严格统一为 42px；
  - **单元格内按钮尺寸统一**：操作按钮统一使用 `.table-action-btn`（高度固定 26px），严格禁止撑高单元格；
  - **单行不换行与超出省略截断**：单元格文字采用 `nowrap` 配合 `ellipsis`，长文本列（如参数说明）扩宽至 260px，兼顾整洁与阅读空间；
  - **完整边框闭合**：表格单元格四周完整闭合 1px 细边框，规整严密。
- **基于 React Portal 的自定义 Tooltip 悬浮气泡**：彻底停用并清理浏览器原生 `title` 属性，通过 Portal 挂载到顶层 DOM，彻底解决表格单元格 `overflow: hidden` 导致的悬浮截断问题，具备深色半透明微质感胶囊外观与平滑动画。
- **东八区无 T 时间格式化规范**：统一封装 `formatBeijingTime` 工具，将所有后端 UTC/ISO 时间格式化为 `Asia/Shanghai` 东八区时间（`YYYY-MM-DD HH:mm:ss`），严格剔除字符 `T` 与毫秒偏移。
- **全局统一分页控件**：统一封装并在所有表格底部集成 `Pagination` 组件，支持记录总数统计、每页条数选择器（5/10/20/50 条）以及上一页/页码/下一页翻页切换。
- **选择文件与表单控件微质感优化**：重构 `input[type="file"]` 及选择按钮样式，保持原有 26px 小巧尺寸不变，去除浏览器系统原生灰框，赋予白底、主色边框与平滑悬停动效。
- **环境配置严格对齐**：核对并对齐 `.env` 与 `.env.example`，补齐部署反馈 HMAC 密钥与防重放过期配置项。

## 升级步骤

1. 拉取最新代码并同步 Python / 前端环境：

   ```powershell
   # 安装 Python 开发依赖
   python -m pip install -e ".[dev,postgres,s3]" -c constraints.txt

   # 构建前端生产资源
   cd frontend
   npm run build
   cd ..
   ```

2. 启动服务进行手动体验与验证：

   ```powershell
   python start.py
   ```

   在浏览器中打开 `http://127.0.0.1:8080/` 即可直接体验全新的 Tab 选项卡、全边框数据表格、序号列、自定义 Tooltip 与无 T 东八区时间。
