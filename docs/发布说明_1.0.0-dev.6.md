# Scenara Model 1.0.0-dev.6 更新说明

发布日期：2026-09-07

## 变更摘要

- **Core 统一认证与委托身份上下文接入**：
  - 新增 `SCENARA_MODEL_AUTH_MODE=core` 鉴权模式，支持基于 HMAC-SHA256 签名（`X-Scenara-Context-Signature`）和时间戳（`X-Scenara-Context-Timestamp`）防重放验证的 Core 委托身份上下文；
  - 自动解析透传租户（Tenant）、项目（Project）、主体（Principal）、范围（Scopes）和产品授权（Entitlements），实现多租户隔离与细粒度安全访问控制；
  - 规范服务间通信凭证安全，要求服务密钥（`SCENARA_MODEL_SERVICE_TOKEN`）与上下文签名密钥（`SCENARA_MODEL_CONTEXT_SIGNING_KEY`）严格区分且满足强度阈值。
- **Data 数据平台已发布数据集版本对接**：
  - 新增 `scenara_model.data_platform.DataPlatformClient` 客户端，支持在 Core 委托身份下直接向 `scenara-data` 服务拉取已发布的 Dataset Version 及其不可变清单（Manifest）；
  - 数据集版本引用时自动下载并缓存至本地 workspace，校验引用元数据与不可变清单一致性；网络或跨服务异常时失败关闭，杜绝脏数据注入。
- **环境隔离与生产安全门禁**：
  - 引入 `SCENARA_MODEL_DEPLOYMENT_PROFILE` 区分 `development` 与 `production` 环境；
  - 生产环境下强制实施安全收敛：强制 `auth_mode=core`、强制 PostgreSQL 元数据存储、强制 S3/MinIO 存储后端、强制启用 Webhook 签名与数据平台 HTTPS 访问，禁用内置本地登录；
  - 支持 `_FILE` 后缀环境变量（如 `SCENARA_MODEL_METADATA_DB_FILE`），原生兼容 Docker Secrets / Kubernetes Secrets 挂载。
- **生产与联调部署编排加固**：
  - 新增生产环境 Compose 配置 `deploy/compose.production.yml`，执行非 root 最小特权运行、`read_only: true` 只读根文件系统、`cap_drop: ALL`、`no-new-privileges: true` 及 Docker 敏感凭据全量挂载；
  - 新增跨服务联调 Compose `deploy/compose.shared-test.yml` 及配套环境变量模板 `deploy/shared-test.env.example`；
  - 新增自动化静态门禁校验脚本 `scripts/production_gate.py` 并接入 GitHub CI 流水线。
- **环境变量配置严格完全对齐**：
  - 全面梳理并同步 `.env` 与 `.env.example`，完整覆盖 Core 认证参数、Data 数据服务对接、多环境 Profile、存储与安全密钥声明。
- **流水线启动模板与标签规范优化**：
  - 流水线模板明确区分生产真实训练与自检冒烟基线，防止基线模型被误用于生产链路；
  - 实时执行日志流与归档产物标签实现全中文化与语义高亮展示；
  - 前端 UI 时间展示彻底去除冗余的“ (东八区)”后缀，以标准东八区时间展示。

## 升级步骤

1. 拉取最新代码并同步 Python / 前端环境：

   ```powershell
   # 安装 Python 开发依赖及相关附加包
   .\.venv\Scripts\python.exe -m pip install -e ".[dev,postgres,s3]" -c constraints.txt

   # 构建前端生产资源
   cd frontend
   cmd /c npm run build
   cd ..
   ```

2. 检查并对齐本地环境变量 `.env`：

   对比 `.env.example`，根据当前部署需求选择配置 `SCENARA_MODEL_AUTH_MODE`（本地开发使用 `local`，生产使用 `core`）及相关凭据。

3. 启动服务或运行门禁验证：

   ```powershell
   # 验证生产部署配置门禁
   python scripts/production_gate.py

   # 运行全量测试
   .\.venv\Scripts\python.exe -m pytest

   # 本地启动
   python start.py
   ```
